# Archive

Historical development artifacts kept for reference. They are **not** required to build or run LC-Seq.

| Path | Contents |
|------|----------|
| `notebooks/` | Pre-app Jupyter prototypes (null-tree analysis, chromatogram plotting, RT calculation). Logic has been ported into `src/`. |
| `lcseq-standalone/` | Earlier standalone xlsx loader, CLI, and debug plots (see `lcseq-standalone/README.md`). |

For current developer onboarding, see [../README.md](../README.md) and in-app help under `src/help/`.
