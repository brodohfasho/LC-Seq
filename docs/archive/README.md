# docs/archive

Historical development artifacts kept for reference. They are **not** required to build or run LC-Seq.

| Path | Contents |
|------|----------|
| `notebooks/` | Pre-app Jupyter prototypes (null-tree analysis, chromatogram plotting, RT calculation). Logic has been ported into `src/`. |
| `INTEGRATION_PLAN_LCSEQ_ANALYSIS.md` | Phase-by-phase implementation plan for pedigree, lineage, and DEL-cycle work. Most items are complete; kept for historical context. |
| `lcseq-standalone/` | Colleague's standalone xlsx loader, CLI, and debug plots (see `lcseq-standalone/README.md`). |

For current developer onboarding, use [DEVELOPER_SETUP.md](../DEVELOPER_SETUP.md) and in-app help under `src/help/`.
